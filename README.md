# Math Wizard

A math practice adventure for grades 1–6. The student is a wizard or a witch who fights monsters by casting spells from a spell book: every spell has a number, and the answer to a math problem is the spell that is cast.

Built from the Hebrew reading game `learning-to-read`.

- **Specs** (the source of truth): [`specs/`](specs/). Start with [`specs/HANDOFF.md`](specs/HANDOFF.md).
- **Live site:** the `main` branch, served at the root.
- **Test site:** the newest `test-*` branch, served under `/test/`.

Every phase goes to the test site first. The project owner approves before anything goes live.
